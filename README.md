# Deep Fight

Om spillet
Deep Fight er et tekstbasert kamp- og overlevelsesspill laget i Python. Spillet er inspirert av Deepwoken.

Hvordan spille
1. Skriv inn navnet ditt.
2. Velg et våpen: Light, Medium eller Heavy.
3. Kjemp mot fiender gjennom flere floors.
4. Velg mellom attack, block og parry.
5. Prøv å beseire alle fiendene for å vinne.

Funksjoner
- Ulike våpen med forskjellig skade.
- Flere fiender med økende vanskelighetsgrad.
- Attack, block og parry.
- Tilfeldig skade i kampene.
- Bonus på skade etter Floor 2.
- Game over hvis spilleren mister all HP.

Klasser
`Character`: Grunnklasse for karakterer.
`Player`: Spillerklassen som arver fra Character.
`Enemy`: Fiendeklassen som arver fra Character.
`Weapon`: Holder informasjon om våpen.
`Game`: Styrer spillet og kampene.

Hvordan starte spillet
Kjør Python-filen som inneholder Game-klassen og oppstarten av spillet.
